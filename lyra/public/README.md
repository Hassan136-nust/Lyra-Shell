# Public Assets Folder

## 📁 What Goes Here?

This folder contains static assets that are served directly by the app.

## 🖼️ Wallpaper Setup

**To add your wallpaper:**

1. Place your image here: `public/wallpaper.jpg`
2. Supported formats: `.jpg`, `.png`, `.webp`, `.gif`
3. Recommended resolution: 1920x1080 or higher
4. The app will automatically load it on startup!

## 📝 Current Files

- `wallpaper.jpg` - Your desktop wallpaper (add this file)
- `vite.svg` - Vite logo (default, can be removed)

## 🎨 Customization

If you want to use a different filename:
- Edit `src/App.jsx`
- Change `url(/wallpaper.jpg)` to your filename
